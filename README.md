# Залетевшие рилсы в своей нише

Пайплайн находит в Instagram рилсы, которые **залетели**, то есть набрали просмотров кратно больше, чем подписчиков у автора, снимает с них **расшифровку речи** и помогает собрать **разбор хуков** и накопительный **банк** залетевших роликов под твою нишу.

Интересен не большой аккаунт, а ролик-выброс: 300 тыс. просмотров у автора с 5 тыс. подписчиков значит, что алгоритм разнёс ролик далеко за пределы его аудитории. Поэтому главная метрика:

```
залёт (ratio) = просмотры / подписчики
```

## Как это работает

```
ключевые слова ниши
   │
   ▼  1. Apify: поиск аккаунтов по словам (apify/instagram-scraper)
аккаунты ниши любого размера + число подписчиков
   │
   ▼  2. Apify: рилсы этих аккаунтов (apify/instagram-reel-scraper)
рилсы с просмотрами и ссылкой на видео
   │
   ▼  3. отбор выбросов: просмотры >= порога И ratio >= порога
топ залетевших
   │
   ▼  4. ffmpeg вытаскивает звук -> Groq Whisper -> расшифровка
   ▼  5. (по желанию) Groq разбирает хук: что цепляет, приём, идея, что забрать себе
отчёт .md + сырые данные .raw.json
   │
   ▼  6. viral_bank.py: кандидаты -> ты выбираешь по смыслу -> расшифровка -> банк
банк залетевших bank.md (копится, новое сверху)
```

## Что нужно

- Python 3.9+ (только стандартная библиотека, `pip install` не нужен)
- `curl` и `ffmpeg` (Mac: `brew install ffmpeg`, Ubuntu: `sudo apt install ffmpeg curl`)
- для режима YouTube дополнительно `yt-dlp` (`pip install yt-dlp`)
- ключ **Apify** и ключ **Groq**

## Ключи

Ключи свои, у каждого. Берёшь на Apify и добавляешь в файл `.env`:

```bash
cp .env.example .env
```

Открой `.env` и впиши:

- `APIFY_API_TOKEN` - ключ берёшь на [console.apify.com](https://console.apify.com) -> Settings -> API & Integrations -> Personal API tokens. Бесплатный план даёт $5 в месяц.
- `GROQ_API_KEY` - ключ берёшь на [console.groq.com/keys](https://console.groq.com/keys). Нужен для расшифровки и разбора хуков.

Можно не создавать `.env`, а передать ключи переменными окружения: `export APIFY_API_TOKEN=...`.

Если ключей Apify несколько (`APIFY_API_TOKEN_2`, `APIFY_API_TOKEN_3`...), скрипт сам берёт тот, у которого больше остаток на месяц.

**`.env` никому не отправляй и в git не добавляй** (он уже в `.gitignore`).

## Быстрый старт

```bash
mkdir -p out

python3 apify_reels_scout.py auto \
  --keywords "фитнес дома,похудение,тренировки для женщин,правильное питание" \
  --niche "фитнес для женщин" \
  --lang ru \
  --min-followers 3000 --min-ratio 1.5 --max-age-days 183 \
  --analyze \
  --out out/fitness-ru.md \
  --raw out/fitness-ru.raw.json
```

Через 10-20 минут в `out/fitness-ru.md` будет отчёт: таблица залетевших (залёт, просмотры, подписчики, лайки, комменты, длина, ссылка) и полные расшифровки с разбором хука.

Для англоязычного рынка (США) - английские ключевые слова и `--lang en`.

### Пробный прогон за копейки

Чтобы проверить, что ключи работают, не тратя бюджет:

```bash
python3 apify_reels_scout.py auto --keywords "фитнес дома" \
  --search-per 3 --max-accounts 2 --reels-per 3 --top 3 --transcribe 1 \
  --out out/test.md --raw out/test.raw.json
```

## Флаги

| Флаг | Что делает | По умолчанию |
|---|---|---|
| `--keywords` | ключевые слова через запятую, по ним ищутся аккаунты ниши | обязательно |
| `--niche` | название ниши, подставляется в разбор хуков и заголовок отчёта | пусто |
| `--search-per` | сколько аккаунтов брать на одно слово | 18 |
| `--max-accounts` | сколько аккаунтов скрейпить всего | 40 |
| `--reels-per` | рилсов с каждого аккаунта | 15 |
| `--min-views` | порог просмотров (сам снижается, если выбросов мало) | 20000 |
| `--min-ratio` | минимальный залёт (просмотры / подписчики) | 3.0 |
| `--min-followers` | минимум подписчиков у автора (режет микро-аккаунты с раздутым залётом) | 0 |
| `--max-age-days` | только рилсы не старше N дней | 0 (без фильтра) |
| `--top` | сколько залетевших в отчёт | 20 |
| `--transcribe` | сколько из топа расшифровать | 20 |
| `--lang` | язык расшифровки: `ru`, `en`, `auto` | ru |
| `--analyze` | разбор хука каждого ролика через Groq | выкл |
| `--out` | куда положить отчёт .md | обязательно |
| `--raw` | куда положить сырые данные .json (нужны для банка) | нет |

## Сколько стоит

- Apify (бесплатный план $5/мес): рилс ~$0.0026, запуск актора $0.001, аккаунт ~$0.0023. Прогон на 40 аккаунтов по 15 рилсов ≈ $1.5-2.
- Groq Whisper: копейки, на бесплатном ключе обычно хватает.

Проверить остаток Apify:

```bash
curl -s -H "Authorization: Bearer $APIFY_API_TOKEN" https://api.apify.com/v2/users/me/limits
```

## Полный цикл: от сбора к банку хуков

Автоотбор по залёту приносит и мусор: бренды, рейдж-контент, чужие языки, ивенты. Поэтому лучший результат даёт ручной отбор по смыслу.

**1. Сбор.** Прогон `auto` как выше, обязательно с `--raw`. Удобно гонять сразу два рынка: RU (`--lang ru`) и US (`--lang en`).

**2. Кандидаты по абсолютным просмотрам:**

```bash
python3 viral_bank.py candidates --raw out/fitness-ru.raw.json --top 60 --exclude-owner brand1,brand2
```

Смотришь глазами и выбираешь 15-25 роликов по теме. Ссылки кладёшь в файл, по одной на строку:

```
# out/fitness-ru-urls.txt
https://www.instagram.com/p/XXXXXXXX/
https://www.instagram.com/p/YYYYYYYY/
```

**3. Расшифровка и разбор выбранных:**

```bash
python3 viral_bank.py transcribe --raw out/fitness-ru.raw.json \
  --urls out/fitness-ru-urls.txt --lang ru --out out/fitness-ru-curated.json
```

Сохраняет по мере работы (файл `.part`), можно прервать.

Ссылки на видео в Instagram живут недолго (часы). Если между сбором и расшифровкой прошло много времени, расшифровка вернёт пусто - пересобери шаг 1.

**4. Разбор.** Читаешь расшифровки и пишешь разбор: у каждого ролика механика хука из каталога (шаблон в [examples/hook-mechanics-template.md](examples/hook-mechanics-template.md)) и четыре строки:

- **цепляет:** что останавливает в первые 1-2 секунды;
- **вопрос зрителя:** какой вопрос у него появляется, дословно от его лица;
- **почему досматривает:** что держит интригу и что он получает в конце;
- **принцип для нас:** что переносим на свою тему (принцип, а не внешнюю форму).

Ролик, у которого не получается сформулировать «вопрос зрителя», в разбор не берём: он залетел не хуком (бренд, музыка, лицо), переносить нечего.

**5. В банк:**

```bash
python3 viral_bank.py bank-add --curated out/fitness-ru-curated.json \
  --bank bank.md --market "РФ" --topic "фитнес" --only-from razbor-fitness.md
```

`--only-from` кладёт в банк только ролики, на которые ссылается твой разбор. Банк накопительный: новая порция сверху, дубли по ссылке пропускаются, старое не стирается.

## Режим YouTube

Тот же поиск залетевших (просмотры / подписчики канала), но по YouTube Shorts и длинным видео, без Apify:

## Грабли

- **Ключ Apify отвечает 403 «Monthly usage hard limit exceeded»** - кончились $5 месяца. Добавь второй ключ `APIFY_API_TOKEN_2`.
- **Широкие слова тащат мусор.** «dopamine» затянул бренды и ивенты, «кредиты долги» - котельные. Бери узкие слова, как их пишут авторы ниши.
- **Whisper галлюцинирует на тишине и музыке** («Субтитры сделал...», «Спасибо за просмотр»). Такие ролики помечаются как без речи: это формат «текст на экране», смотри подпись.
- **Видео не скачивается** - ссылки Instagram протухают за несколько часов, расшифровывай сразу после сбора.
- **Groq отвечает 403 «Access denied»** - Groq закрыт для части стран и хостингов. Запускай с другой сети или через VPN.

## Безопасность

Ссылки на видео от Instagram и YouTube считаются недоверенным входом: скрипт пускает в загрузку только http(s) на публичные адреса, ключ Groq передаётся в curl через stdin (не виден в `ps`), ключ Apify - в заголовке, а не в URL (запасной путь через URL включается, только если Apify не принял заголовок), токены вычищаются из логов.
